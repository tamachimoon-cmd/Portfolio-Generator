# Como contribuir

1. Abra uma issue descrevendo a melhoria ou correção.
2. Crie uma branch a partir de `main`.
3. Mantenha a mudança pequena e independente.
4. Execute `npm run check` e `npm test`.
5. Não inclua dados pessoais, credenciais ou conteúdo corporativo.
6. Abra um Pull Request explicando impacto e validação.
